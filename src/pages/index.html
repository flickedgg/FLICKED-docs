Alpha · Working end to end on a real server {{icon:right:size-3.5 text-subtle}}

Competitive CS2.
Self-hosted.

FLICKED is a free, open-source platform for running your own CS2 ladder: matchmaking, parties, ratings, match history and demos. You bring the servers. FLICKED finds the players, makes the match, tells one of your servers to run it, and records what happened.

{{icon:rocket:size-4}}Quickstart How it fits together 
# 1. the database
docker compose up -d

# 2. the backend, on http://localhost:5165
cd backend/Flicked.Api && dotnet run --launch-profile https

# 3. the launcher
cd launcher && npm install && npm run tauri dev

Alpha software. Things will change and break. If something is off, that is worth reporting, not assuming it is expected.

What FLICKED does

{{icon:swords:size-5}}

Matchmaking

Queue solo or with a party and get matched with players of a similar rating. The window widens the longer you wait.

{{icon:vote:size-5}}

Map vote

Everyone accepts, then everyone votes. The highest vote wins and ties are settled at random.

{{icon:server:size-5}}

Server pool

Owners register their CS2 servers once. FLICKED hands one out per match and takes it back when the match ends.

{{icon:trend:size-5}}

Ratings and history

Every match updates ratings and is kept, with its demo. A win never loses you rating.

{{icon:users:size-5}}

Parties

Invite friends and queue as one. Parties are always drafted whole onto the same team.

{{icon:box:size-5}}

Self-hosting

One docker compose up for the database, and the API migrates itself on startup.

What it does not do

Being clear about this saves everyone time.

{{icon:ban:size-5}}

No server hosting

It coordinates CS2 servers you already run. It does not create or host them.

{{icon:shield:size-5}}

No anti-cheat

Use a community anti-cheat on your servers if you need one.

{{icon:flag:size-5}}

Not a Valve service

It has nothing to do with official CS2 matchmaking.

Why these lines are drawn where they are is written down in Roadmap & decisions.

The pieces

Four programs and a database. The backend owns every decision; everything else asks it.

Project status

The whole path works end to end, on a real server, with real people: two players signed in through Steam, queued, accepted, voted a map, and CS2 connected them itself. The match finished and the result was written to Postgres.
